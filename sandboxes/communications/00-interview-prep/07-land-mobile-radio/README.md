# Module 07 — LMR (Land Mobile Radio) interview worksheet packs

Prepared for an **Etherstack** interview. Etherstack's core business is **LMR protocol stacks** (P25, DMR, TETRA, dPMR, analogue/MPT-family — VERIFY the current product list).
Audience: starts from zero, C++17/20, first principles only.

> **SAFETY / LEGAL — synthetic frames only.** Every example, test and build in this module uses **synthetic** frames, identities and arithmetic generated by the unit tests.
> **Never** receive, record or decode live public-safety or commercial radio traffic with this material (or with an SDR). It may be unlawful, and encrypted traffic is off-limits by design.
> Reading the open-source decoders OP25, dsd-fme and SDRTrunk is *optional study*; do not copy their copyrighted code. No cipher is implemented anywhere here.

## Building

Flags: `-Wall -Wextra -fsanitize=address,undefined` (MSVC: `/W4`). AddressSanitizer needs gcc/clang on Linux, macOS or WSL.

```bash
cd <pack>/code
cmake -S . -B build && cmake --build build -j && ctest --test-dir build --output-on-failure   # stubs: tests FAIL until you implement them
cmake -S . -B build_sol -DLMR_USE_SOLUTIONS=ON && cmake --build build_sol -j && ctest --test-dir build_sol   # reference solutions
```

GoogleTest v1.14.0 is fetched with CMake `FetchContent` (network needed on first configure).

## Honest status

The packs were written without a C++ compiler, CMake or network on the authoring machine, so **nothing has been compiled or run**. Numeric claims were derived by hand and cross-checked inside the documents;
standards facts that could not be confirmed are marked **VERIFY** (each worksheet ends with a VERIFY list). Treat the first `ctest` run as the real test of the code.
